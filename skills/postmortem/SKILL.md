# Postmortem playbook

Sections, in order:

1. **Summary** — two sentences a VP can read.
2. **Impact** — who was affected, for how long, how badly.
3. **Timeline** — detection, escalation, mitigation, resolution (with times).
4. **Root cause and contributing factors** — systems, not people. Blameless.
5. **What went well / what didn't.**
6. **Action items** — each with an owner and a due date. File them as follow-ups.

Ask the reviewer to check that the root cause is actually supported by the timeline.
